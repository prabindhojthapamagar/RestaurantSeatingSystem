# Restaurant Seating System - Version 3

## Version

V3 - Creating zones and assigning seats according to preferences and zones. Example: elder guests near buffet, guest with children in sofa seat. 

## Project Goal

Create a Java application that automatically assigns restaurant tables to reservations instead of manually assigning them through Excel.

Extend Version 2 by introducing reservation based on preferences on zone.
Instead of assigning seats on the basis of only number of guests, new version assignes seat looking at the preferences of guest as well.
